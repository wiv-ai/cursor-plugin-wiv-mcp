# Changelog

## 1.1.0

- Switched the hosted server configuration from legacy SSE to Streamable HTTP at `https://mcp.wiv.ai/mcp`.
- Replaced placeholder API-key configuration with Cursor's browser-based Wiv OAuth flow.

- Initial Cursor Marketplace plugin for WIV Workflow MCP.
- Remote (SSE) connection to hosted WIV MCP with URL and X-API-Key.
- Plugin manifest, README, and optional rules/skills for discovery.
